# Student feedback

Use a teacher-owned Microsoft Forms or Google Forms form. Put its public responder HTTPS link in `web_src/feedback-config.json` under `url`, then build/deploy. An empty URL keeps the link hidden; no inactive button is shown. The sidebar link opens in a new tab and does not submit student workspace data. Responses are collected in the form owner's account, separately from project ZIPs.

Suggested form title: QuickBite course feedback

Intro: Help improve the website and course instructions. Feedback is optional and does not affect your grade. Do not include passwords or personal data.

Questions:
- Which module or page are you commenting on? (optional)
- What worked well? (optional long text)
- What was unclear or did not work? (optional long text)
- What would you change? (optional long text)

Allow responses from students without requiring an account if your institutional settings permit it. Do not promise anonymity until you check the form's identity settings. Keep the response/results link private; configure only the responder link on the website. Confirm one test response arrives before publishing.
